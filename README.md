# Knowledge Vault

A clean and simple knowledge management website designed to organize and connect notes in one place.

## 📌 Project Overview

Knowledge Vault is a simple and modern website created to help users organize their notes, ideas, and learning resources.

The main goal of this project is to create a clean interface where information can be stored and connected in an easy way.

## ✨ Features

- Clean and modern design
- Navigation menu
- Hero section with call-to-action buttons
- Notes section
- Knowledge management section
- Information cards
- Call-to-action section
- Clean footer design

## 🛠️ Technologies Used

- HTML5
- CSS3
- Font Awesome
- Google Fonts
